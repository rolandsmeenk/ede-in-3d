# Lunteren landmark survey

The 22 November 2026 survey uses BAG and 3DBAG LoD 2.2 for eight building shells, OpenStreetMap contributors for public approaches, and the 2026 PDOK high-resolution orthophoto for unmapped structures. The heights retain the 22.54 m NAP Oude Kerk datum. The bake converts horizontal data in RD New through the pinned project GIS module. Photographs inform geometry and materials. All in-game surfaces use original geometry, shared materials, and locally generated sign lettering.

Regenerate the 47 KB module with a dated cache. On an empty cache, use `--fetch` for the eight public CityJSON records and the matching ProRail canopy. The reviewed image coordinates and approach points are recorded directly in the script. No API is contacted during gameplay.

```sh
uv run --python 3.12 --with pyproj==3.8.0 --with 'shapely>=2.1' python -B \
  tools/build-ede-lunteren-survey.py /path/to/dated-cache --fetch
uv run --python 3.12 --with pyproj==3.8.0 --with 'shapely>=2.1' python -B \
  tools/build-ede-lunteren-survey.py /path/to/dated-cache --check
node --test tests/ede-lunteren-landmarks.test.cjs
```
