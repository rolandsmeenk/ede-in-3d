# Ten Ede exterior landmarks and the De Vuurvogel tree

The November 2026 batch follows the [Ede landmark survey catalogue](ede-landmark-exteriors.md). The game bundles the exterior meshes, paint and measurement data locally. The ordinary Teleport menu has one approach per destination. Prospective campus changes were left out of the reference set.

## Sources and fit

The offline surveys retain 3DBAG LoD 2.2 roof and wall geometry, convert Dutch RD New through the pinned GIS frame, and keep elevations relative to the original 22.54 m NAP Oude Kerk datum. OSM identifies the fallback footprints and the public approach paths. The registry matches 19 exact BAG IDs in streamed tiles and 22 OSM IDs in the fallback map. Nearby buildings, including the hospital garage, remain independent. Exterior photographs informed the openings, colour and trim. Shared materials supply brick, glass, stone and metal finish. Signs and the NIZO mural have separate surfaces. General terrain still uses the 12 m AHN field. The De Vuurvogel tree is at **RD 173755.75 E, 450107.75 N**, rendered at **scene X −752.4, Z 782.0**. ## Performance

Two alternating before-and-after pairs ran on an Apple M4 Pro with Chrome 152 WebGPU, the Fast preset and a 1080 × 640 viewport. The baseline was commit `481a315`. Both conditions replayed the same 12 camera routes with the same simulation clock, midday lighting, and paused traffic updates during the samples. Each route recorded 48 frames after 36 pre-roll frames. Startup ranges include both trials. The draw counts below are medians across the two runs. The p95 column retains the per-run spread where it changed meaningfully.

| --- | ---: | ---: |
| Cold first playable frame | 9.98–10.02 s | 10.42–10.53 s |
| Warm first playable frame | 9.97–10.02 s | 10.60–10.63 s |
| Cold bytes transferred before first playable | 27.46–27.48 MB | 27.78–27.82 MB |

| Peak startup JS heap and backing storage sampled via Chrome | 2.37–2.55 GB | 2.40 GB |

## Refresh

Reuse the cached surveys for repeatable bakes. Add `--fetch` to retrieve missing files. Review updated exterior references and wall or entrance anchors before accepting a different upstream survey. The NIZO mural uses its separate [offline paint bake](ede-research-landmarks.md#nizo-food-research).

```sh
uv run --with pyproj==3.8.0 --with rasterio python -B tools/build-ede-next-survey.py /tmp/ede-next
uv run --with pyproj==3.8.0 python -B tools/build-ede-estate-survey.py /tmp/ede-estate
uv run --with pyproj==3.8.0 python -B tools/build-ede-venue-survey.py /tmp/ede-venues
uv run --with pyproj==3.8.0 python -B tools/build-ede-research-survey.py /tmp/ede-research
```
